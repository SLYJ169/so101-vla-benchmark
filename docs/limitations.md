# 项目局限

为了保持结果可信，以下边界明确保留：

1. **每个模型只有 20 次正式真机测试。** 因此同时保留原始计数 15/20、17/20、19/20，不把小样本结果夸大为绝对性能。
2. **三组位置不是严格逐坐标配对。** 可以称为同平台、同任务、同数据集、相似协议下的真实机器人对比。
3. **OOD 测试是定性探索。** 支持“有限跨物体泛化”，不支持“任意新物体通用抓取”。
4. **对新几何形状的 grasp adaptation 仍有限。** 目标识别和到达通常好于抓取几何自适应。
5. **光照鲁棒性没有做严格 A/B 量化。** SmolVLA 曾出现白天效果下降的迹象，但这里只作为定性观察。
6. **完整原始数据和大模型 checkpoint 不提交 Git。** 仓库主要保留配置、评测证据、代表脚本和 Demo。
7. **RTC / Async inference 不属于 P1。** 正式 Benchmark 中没有加入，避免改变冻结控制链。
