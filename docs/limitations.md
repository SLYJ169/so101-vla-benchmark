# 评测说明

- 每个模型的正式真机测试为 20 次，因此结果同时保留原始计数：15/20、17/20、19/20。
- 三组测试位置不是逐坐标配对，适合作为同平台、同任务、同数据集下的工程对比。
- OOD 属于额外的定性测试，不计入正式 20-trial。
- π0.5 对未见物体的目标定位和任务执行有一定迁移能力，但几何形状变化后抓取稳定性仍会下降。
- SmolVLA 曾观察到白天/夜间表现差异，但没有做严格的光照 A/B 测试。
- 完整 Final50、原始长视频和大模型 checkpoint 不直接提交到 Git。
- RTC / Async inference 不属于 P1，正式 Benchmark 中未启用。
