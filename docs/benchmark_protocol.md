# Benchmark 协议

ACT、SmolVLA、π0.5 均在同一套 SO-101 硬件、同一任务和同一份 Final50 数据上进行 20 次测试。

## 成功判据

完整完成以下过程记为成功：

1. 抓起目标；
2. 搬运至盒子；
3. 将目标放入盒子。

| 模型 | Checkpoint | Final Completion |
|---|---:|---:|
| ACT | 80k | **15/20** |
| SmolVLA | 20k | **17/20** |
| π0.5 | 6000 updates / dir 5999 | **19/20** |

π0.5 使用第二组 clean 20-trial 作为正式结果。

三组测试使用相同平台、任务和数据集，但目标位置不是逐点一一对应。
