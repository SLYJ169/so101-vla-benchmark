# Benchmark 协议

三种模型均在同一套 SO-101 硬件和同一任务下进行 **20 次自动执行测试**。

## 成功判据

机器人必须完成完整任务：

1. 抓起目标；
2. 将目标运输至盒子；
3. 最终将目标放入盒子。

首页只报告 **Final Completion**。

| 模型 | Final Completion |
|---|---:|
| ACT 80k | **15/20** |
| SmolVLA 20k | **17/20** |
| π0.5 Full-FT 6000 | **19/20** |

π0.5 使用第二组 clean 20-trial 作为正式结果。

三组实验使用同平台、同任务、同数据集和相似测试协议，但并非严格逐坐标 paired experiment。
